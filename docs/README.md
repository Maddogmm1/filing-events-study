# Study records

Working records written during the study, in the order they were produced. They are published as written apart from
removing local paths. Mentions of runner scripts (`*.bat`), `results/...` files and branch names refer to the private
working folder and research terminal where the study was run; the aggregated run results are in
`../results/experiments_dev.json`.

| File | What it is |
|---|---|
| `FINAL_REPORT.md` | The conclusion and everything needed to judge it |
| `RESULTS_MAIN.md`, `RESULT_H1.md` | Result write-ups for the seven main trials |
| `LOCK_RECORD.md` | Pre-registration record (protocol hash, frozen run order) |
| `READINESS_v1.md`, `READINESS_v2.md`, `READINESS_v3.md` | Data-readiness checks before lock (timestamps, counts, survivorship, costs) |
| `DELISTING_AUDIT_1.md`, `DELISTING_AUDIT_2.md` | Hand audits of the delisting-cause rule (the second failed its pre-set bar, and how that was handled) |
| `PRICE_REVIEW.md` | Identity and price-spike review behind the 617 price masks |
